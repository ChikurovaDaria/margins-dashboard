# Материалы для отправки

Формат по заданию:

```text
ФИО: [вписать ФИО Даши]
Сайт: [ссылка после публикации]
Репозиторий: [ссылка на Git-репозиторий]
```

## Перед отправкой

- [ ] заменить ФИО в шаблоне выше;
- [ ] выполнить `npm run check`;
- [ ] выполнить `npm run build`;
- [ ] опубликовать содержимое `dist/`;
- [ ] открыть опубликованный адрес и проверить оба API-виджета;
- [ ] убедиться, что преподавателю доступен репозиторий;
- [ ] уметь объяснить наследование, полиморфизм, `AbortController` и метод `destroy()`.
