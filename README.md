# MARGINS

Тематический дашборд для неспешного планирования путешествий. Учебный проект на чистом JavaScript демонстрирует ООП, ES-модули, работу с DOM и внешними API.

## Концепция

MARGINS построен как редакционный путевой кабинет: пользователь собирает на рабочем столе независимые инструменты для подготовки поездки и наблюдений в пути.

## Возможности

- динамическое добавление, удаление, сворачивание и изменение порядка виджетов;
- независимое состояние каждого экземпляра;
- список вещей с добавлением, отметкой и удалением пунктов;
- локальный генератор полевых заметок;
- профиль страны и свежие данные о населении через World Bank API;
- календарь государственных праздников через Nager.Date API;
- состояния загрузки, пустого результата, ошибки и успеха;
- отмена устаревших запросов через `AbortController`;
- клавиатурное управление, видимый фокус и кнопочная альтернатива перетаскиванию.

## Архитектура

```text
index.html
main.js
js/
├── UIComponent.js    # абстрактный класс: DOM-каркас и жизненный цикл
├── Dashboard.js      # коллекция виджетов и фабрика экземпляров
├── PackingWidget.js  # локальный список вещей
├── FieldNoteWidget.js # локальные идеи для наблюдений
├── CountryWidget.js  # World Bank API
└── HolidayWidget.js  # Nager.Date API
styles/
├── main.css          # дизайн-система, каркас и адаптивность
└── components.css    # состояния и стили виджетов
```

Все конкретные виджеты наследуются от `UIComponent`. Базовый класс создаёт общий DOM-каркас, регистрирует обработчики, управляет сворачиванием и освобождает ресурсы в `destroy()`. `Dashboard` работает с любым виджетом через единый интерфейс.

## API и безопасность данных

- [World Bank API](https://datahelpdesk.worldbank.org/knowledgebase/topics/125589-developer-information) — название, столица, регион, уровень дохода и свежая оценка населения.
- [Nager.Date](https://date.nager.at/) — государственные праздники выбранной страны и года.

Оба API не требуют секретных ключей. Ответы считаются недоверенными: пользовательские и сетевые данные добавляются в DOM через `textContent`, без `innerHTML`. Перед новым запросом предыдущий отменяется. При удалении виджета запросы и обработчики событий очищаются.

## Запуск

В Windows можно открыть файл `1 - ЗАПУСТИТЬ САЙТ.bat` — он запустит локальный сервер через Python 3 и откроет сайт в браузере.

Для разработки через Node.js 18 или новее:

```bash
npm run dev
```

Откройте `http://127.0.0.1:4174`. Проверить синтаксис можно командой `npm run check`, собрать папку для публикации — `npm run build`.

## Публикация

Содержимое папки `dist/` можно опубликовать на GitHub Pages, Netlify или другом статическом хостинге. Преподавателю нужны ссылка на опубликованный сайт и ссылка на Git-репозиторий.

## Ограничения

- доступность данных зависит от сторонних сервисов;
- Nager.Date поддерживает не все страны, поэтому список в интерфейсе ограничен проверенными вариантами;
- список вещей хранится только до перезагрузки страницы.
